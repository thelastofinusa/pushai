# Switch provider

`pai switch` lists every provider you've configured (marking the active one)
and lets you pick a new active provider.

```bash
pai switch
```

## How it works

- If no configuration exists yet, it offers to run `pai setup` instead.
- You choose from your saved providers; the active one is marked.
- After switching, `pai` confirms the new active provider.

## Example output

```
configured providers
├─▶ openai [gpt-4o] » active
├─▶ anthropic · claude-3-5-sonnet
╰─▶ local · llama3.2
```

## No options

`pai switch` takes no flags.

:::tip
You can have multiple providers configured (from `pai setup` → "add provider")
and switch between them at any time with `pai switch`.
:::
