# View configuration

`pai peak` lists all of your saved providers, marking which one is active.

```bash
pai peak
pai peak --key
```

## Options

| Flag | Description |
|------|-------------|
| `-k, --key` | Also reveal stored BYOK API keys in plaintext. |

## Examples

:::code-group

```bash
pai peak            # list providers, mark active
pai peak --key      # also show configured API keys
```

:::

## Example output

```
configured providers
├─▶ openai [gpt-4o] » active
│   api key configured
├─▶ anthropic · claude-3-5-sonnet
│   api key configured
╰─▶ local · llama3.2
    no key required
```

> Pass `-k`/`--key` to reveal stored BYOK API keys in plaintext. Use with care
> — this prints secrets to your terminal.

## No configuration yet?

If no configuration exists, `pai peak` offers to run `pai setup` instead.
