# Reset configuration

`pai reset` lets you remove a single saved provider interactively, or delete
all saved providers and your entire configuration at once.

```bash
pai reset
pai reset --all
```

## Options

| Flag | Description |
|------|-------------|
| `-a, --all` | Delete all configuration, including API keys. Skips the interactive menu. |

## Interactive mode

Without `--all`, you're shown your providers and can:

- Remove a single provider (and its API key, if it's a BYOK provider).
- Delete all providers (purges every provider configuration and API key).
- Preserve the current configuration (cancel).

Removing the last provider resets the entire configuration.

## `--all` mode

`pai reset --all` skips the interactive selection and goes directly to the
confirmation prompt:

```
are you sure you want to delete all configuration?
```

It deletes `~/.config/pushai/config.json`, any per-provider key files, and
removes BYOK API keys from your OS keychain.

:::warning
`--all` deletes every provider and every stored API key. This cannot be undone.
:::

## Uninstalling

This does **not** delete `~/.config/pushai` on its own. Run `pai reset`
first if you want your stored config and keys removed too, then:

```bash
npm uninstall -g pushai
```
