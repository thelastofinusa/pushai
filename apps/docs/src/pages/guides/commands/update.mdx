# Check updates

`pai update` checks npm for a newer version of `pushai` and installs it in
place if one is available.

```bash
pai update
```

## How it works

1. Checks the npm registry for the latest `pushai` version (results are cached
   for 24 hours).
2. If you're already on the latest version, reports that you're up to date.
3. If a newer version exists, shows the current vs. latest version and asks
   whether to upgrade.
4. If you confirm, installs `pushai@<latest>` globally using your detected
   package manager (npm, pnpm, yarn, or bun).

## Example output

```
version status
├─▶ latest:     v3.1.24
│   installed:  v3.1.23

upgrade to the latest version (v3.1.24)?
```

## No options

`pai update` takes no flags. A passive update check also runs automatically on
most `pai` invocations (unless you pass `-h`, `--help`, or run `pai update`).
