# Cloud Hosted

A managed, no-key-required cloud mode is planned for PushAI but is **not
available yet**.

When available, you'll be able to select **Cloud Hosted** during `pai setup`
and generate commit messages without providing an API key or installing Ollama.

Track progress in the PushAI repository:
[github.com/thelastofinusa/pushai](https://github.com/thelastofinusa/pushai)

In the meantime, use **Local Models (Ollama)** or **Bring Your Own Key (BYOK)**.

:::warning
Cloud Hosted mode is not available yet. Use Local Models (Ollama) or BYOK in
the meantime.
:::
