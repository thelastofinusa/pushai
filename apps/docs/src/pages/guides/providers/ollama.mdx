# Local Models (Ollama)

Local mode runs AI models on your own machine via
[Ollama](https://ollama.com). No API key is required and your diffs never leave
your machine.

## Setting up a local provider

Run `pai setup` and choose **Local Models (Ollama)**. `pai` will:

1. Check whether Ollama is installed (`ollama -v`).
2. Check whether the Ollama server is running, and start it automatically with
   `ollama serve` if it isn't.
3. List your installed models (`ollama list`).
4. Let you pick a model (or use the only one installed).

## If Ollama isn't installed

`pai` offers to:

- Show the install command for your platform:

  - macOS/Linux: `curl -fsSL https://ollama.com/install.sh | sh`
  - Windows: `irm https://ollama.com/install.ps1 | iex`

- Open the Ollama download page in your browser.

After installing, restart your terminal and run `pai setup` again.

## If no models are installed

`pai` offers to:

- Open the Ollama model library (`https://ollama.com/search`).
- Show the command to pull a model:

  ```bash
  ollama pull llama3.2
  ```

After pulling a model, run `pai setup` again.

## How local generation works

When you run `pai commit` with a local provider:

1. `pai` ensures the Ollama server is reachable at `http://127.0.0.1:11434`.
2. The staged diff is sent to Ollama with a system prompt that instructs the
   model to generate a Conventional Commit message.
3. Ollama returns the message, which you review before committing.

## Notes

- The first request to a newly-pulled model may be slow while Ollama loads it.
- Reasoning models may return empty responses — switch to a non-reasoning model
  if that happens.

:::info
No API key is required and your diffs never leave your machine.
:::
