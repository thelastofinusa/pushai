## @pushai/types

Shared TypeScript types for the pushai monorepo — `SetupMode`, `SetupConfig`,
`AIProvider`, `AIModel`, `OllamaInfo`, and `CommitFlowOptions`. No runtime
code; types only.

```ts
import type { SetupConfig, AIProvider } from "@pushai/types";
```
